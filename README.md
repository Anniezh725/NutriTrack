# NutriTrack

An AI-powered fitness and nutrition tracking application.

## Overview

NutriTrack helps users track their meals, calories, and nutritional goals.   (WIP)
Users can upload food images and use AI to estimate nutritional information. (WIP)

## Planned Features

- User authentication
- Food photo scanning with AI
- Calorie and macro tracking
- Daily nutrition dashboard
- Weight tracking
- Meal history

## Tech Stack

Frontend:
- React

Backend:

Database:

AI:
- Vision API integration
